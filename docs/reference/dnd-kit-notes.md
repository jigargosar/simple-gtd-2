# @dnd-kit

`@dnd-kit/react` is the React binding. Highly configurable: sensors, plugins, modifiers, collision detection, and `useDraggable` / `useDroppable` / `useSortable` hooks compose for everything from simple drag-to-trash to nested sortable lists. Docs: https://dndkit.com/react/quickstart

*Note: `@dnd-kit/core` is an older parallel API; ignore it.*
